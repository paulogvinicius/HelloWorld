# Olá, Mundo em Java ☕

Um projeto simples e direto para dar os primeiros passos na linguagem Java, ideal para entender a estrutura básica de classes, métodos e a execução de código através do terminal.

---

## 🛠️ Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:
* **JDK (Java Development Kit)**: Versão 11 ou superior recomendada.
* Um editor de código (como VS Code, IntelliJ IDEA, Eclipse ou até mesmo o Bloco de Notas).

---

## 💻 O Código

O arquivo principal é o `OlaMundo.java`, que contém a seguinte estrutura:

```java
public class OlaMundo {
    public static void main(String[] args) {
        System.out.println("Olá, Mundo!");
    }
}
